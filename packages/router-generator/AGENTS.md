# Route generator

- Layout: `filesystem/` scans the routing conventions (ported path logic; `utils.ts` holds its helpers), `analyze/route-file.ts` is the only parser user (Yuku: the Route export, its constructor by binding, recorded option keys, offset splices), `scaffold/` writes new route files, `model/` builds the tree model (a pure function of the scan and the per-file facts; nothing of a model outlives a generation), `print/` prints the runtime tree and its types from that model, `publish/` replaces files atomically, `generator.ts` is the session (event queue, one drain loop, per-file facts by content), `watch/` the chokidar watcher of bundlers whose own watcher only sees the bundle.
- Keep writes atomic (temporary file, rename; beside the destination on EXDEV), route file edits guarded by a content recheck before the rename, and change detection content-based: the generator's own writes come back as events and must be no-ops.
- Prettier is only loaded (lazily) when `enableRouteTreeFormatting` is `true`; the printer emits `quoteStyle`/`semicolons` itself.
- Run the complete `test:unit` and `test:integration` targets after generator changes. The fixtures run in copies (no test writes into this package); `test:integration` type-checks the route trees generated there (`tests/integration/fixture-types-*.test.ts`); `test:types` excludes the generator fixtures.
- Add generation cases under `tests/generator/<case>/`. Read [`tests/generator.test.ts`](tests/generator.test.ts) for per-case configuration and preprocessing. Change route inputs/configuration or templates; the test harness generates the route trees (no expected snapshots: the tests read the generated tree through a real router, the type checker and the text the documented output options control).
- `preprocess()` recreates selected route files for `file-modification*` and `custom-scaffolding`. Edit their templates/configuration/preprocessing when changing those inputs; edits to recreated files are overwritten.
- To run one test file or `-t` filter quickly, the slow-tier load gate and the test budgets: [compiler-test-utils/AGENTS.md](../compiler-test-utils/AGENTS.md).
- What these tests are, the spec they cite (`J4.12`, `G3`, `§5.7`) and the known bugs: [compiler-test-utils/oracle/README.md](../compiler-test-utils/oracle/README.md).
