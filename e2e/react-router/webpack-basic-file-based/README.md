# Webpack Basic File-Based E2E

Covers the Webpack SPA fallback configuration documented in the
"Installation with Webpack" guide: `devServer.historyApiFallback` and
`output.publicPath` must allow direct loads and refreshes at nested routes.

To run this example:

- `pnpm install`
- `pnpm dev`

To run the e2e tests:

- `pnpm test:e2e`
