Route code splitting places top-level code by the bindings it reads and writes only, as before the compiler rewrite: a declaration only split code reads moves into that code's chunk whatever is written before or after it (`const Schema = z.object(…)` read by the component now moves past a `validateSearch` schema the route module keeps). What moves keeps its source order in its chunk, what stays its order in the route module. A statement that declares nothing (a call, an assignment, an `if` block) moves with what it changes (the bindings it assigns, writes a property of or calls a method on, also in the local functions it calls): into a chunk when everything it changes goes to that chunk (`const table = createTable(); const columns = snapshot(table); table.addColumn('x')`, only the page reading `columns`, all move, in that order; `plugins.push(sentryPlugin())` and `reg.client = createClient()` move with `plugins` and `reg`, in an `if` or not). Calling an import or passing something to it changes nothing; a statement that changes no binding moves with what it reads (`log(client)`). It stays in the route module, with what it uses, when it changes something the rest of the app sees: another module's object (`Sentry.init(cfg)`, `i18n.use(backend)`), a global (`window.x = …`), `import.meta.hot`, a module it imports dynamically, also through a local function it calls; the `eager-split:written` warning names that cause and the statement's line. Code the compiler cannot see into (`registry.install()` patching `fetch`, with `registry` only read by the page) then runs when the page's chunk loads. Code that depends on another top-level call having run first without reading its result (`const app = initializeApp(config)` read only by the page, before `const auth = getAuth()` kept by the loader) then runs in another order: pass the dependency (`getAuth(app)`) or move both to their own module. A declaration nothing reads is never removed: it moves with what it reads (an unused `function Unused() { return <Page /> }` with `Page`) and the bundler decides.
