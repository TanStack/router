Experimental: The router devtools show route modules. Each mounted module's routes form a collapsible group, nested where the module is mounted, and a filter narrows the route tree to one module. A module panel shows the module's mount path, parent module, routes with their module-local and final paths, and active matches. Matches carry a module badge, and match details show the module, the local path and the final path.
