`vite build --watch`: a rebuild's server bundle now lists the chunks of the client's last build. The server read the start manifest while the client was still rebuilding, so its documents loaded the previous build's client files. The server now waits for the client build that is running, and a server build that embedded another client build than the client's last one (the two watchers report a file at their own times: a fix saved while the client still builds) is built again: the client's build rewrites a small file that the server's watcher watches, in a directory of the run's own in the system's temporary directory (`tanstack-start-<random>`, which only the user can open, removed when the watchers close), also when the app's `build.watch.exclude` covers `node_modules`; an app's `build.watch.include` takes the file in. A `build.watch.exclude` that matches the system's temporary directory is not supported (the server would keep the client build it embedded until a save it bundles). An edit only the client bundles rebuilds the server only when the client's files, their stylesheets or the server functions it calls changed, and an edit saved during the server's first build is followed. A temporary directory that can't be used leaves the build working, with a warning: edits only the client bundles then don't rebuild the server.
