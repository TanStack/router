`vite build --watch`: a rebuild's server bundle now lists the chunks of the client's last build. The server read the start manifest while the client was still rebuilding, so its documents loaded the previous build's client files. The server now waits for the client build that is running, and a server build that embedded another client build than the client's last one (the two watchers report a file at their own times: a fix saved while the client still builds) is built again: the client's build rewrites a small file in the system's temporary directory (`tanstack-start-<digest>/client-build`, one per app) that the server's watcher watches, also when the app's `build.watch.exclude` covers `node_modules`; an app's `build.watch.include` takes the file in. An edit only the client bundles rebuilds the server only when the client's files, their stylesheets or the server functions it calls changed, and an edit saved during the server's first build is followed. Two watch builds of one app at once rebuild each other's server at each client build.
